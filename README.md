\# AI-VOICEK



AI 음성 키오스크 캡스톤 프로젝트



\## 프로젝트 구조



\- `kiosk\_app` : Flutter 키오스크 앱

\- `admin\_web` : 관리자 웹

\- `server` : 서버

\- `ml` : AI 모델

\- `packages/voice\_engine` : 음성 엔진

\- `packages/shared` : 공통 코드

\- `docs` : 문서

\- `hardware` : 하드웨어 관련



\## 개발 환경



\- Flutter

\- Dart

\- Kotlin

\- Python

\- MySQL

\- Oracle Cloud
