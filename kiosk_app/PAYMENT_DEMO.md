# 결제 화면 시연

`codex/payment-screen`에서는 장바구니의 `결제하기`로 시연 화면을 엽니다.
카카오페이 공식 테스트 API 연결은 `server/KAKAOPAY_TEST.md`를 참고합니다. 별도 실행 옵션으로 활성화합니다.
주문 내역과 옵션 포함 총액 확인 → 수단 선택 → 안내 → 결과 확인 순서입니다.

- 카드·카카오페이·네이버페이: 성공/실패 결과를 직접 시연할 수 있습니다. 실제 결제 요청, QR, 단말기 연결은 없습니다.
- 현금: 카운터 결제 안내만 표시합니다. 현금을 받거나 결제 완료로 처리하지 않습니다.
- 취소하면 장바구니를 유지합니다. 마지막 `확인 · 장바구니 비우기`를 눌러야 비웁니다.
- 시연 화면에서는 주문 API와 DB 저장을 호출하지 않으며 실제 주문번호를 발급하지 않습니다.
- 완료 화면은 금액·결제 수단·주문 방식·총 메뉴 수량을 표시합니다. 현금은 수납 대기로 구분하며 테스트 상태와 주문 미접수 사실을 안내합니다.
- 기존 주문 저장 시연은 `--dart-define=PAYMENT_DEMO=false`로 실행할 때 사용합니다. 이 모드는 실제 공용 DB에 주문을 저장할 수 있습니다.

기존 API·키오스크 실행 명령을 그대로 사용합니다. 변경 후 Flutter 터미널에서 대문자 `R`로 재시작합니다.
실제 결제 서비스 연동 시 결제 승인 검증, 금액 재검증, 주문 저장·재시도 정책은 서버와 함께 구현해야 합니다.
