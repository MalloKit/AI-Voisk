# 시작 화면과 주문 화면

## 이번 화면 구성

- 첫 화면: 중앙의 포장 / 매장 식사 버튼. 버튼 위쪽에 포장 봉투와 식사 아이콘을 표시합니다. 선택하면 주문 화면으로 이동합니다.
- 주문 화면 제목: 선택한 식사 방식을 표시합니다. 서버 저장이나 결제 연결은 아직 없습니다.
- 왼쪽 아래 설정: 관리자 / 점주 메뉴. 관리자·점주는 준비 중 안내를 표시합니다.
- 오른쪽 아래 Language와 글자 작게 / 크게: 90~120%, 10%씩 조절합니다. 메뉴·장바구니·선택 창의 글자에 적용하며 음식 아이콘 크기는 유지합니다.
- 왼쪽 카테고리와 가운데 음식 목록에 드래그 가능한 세로 스크롤바가 있습니다.
- 임시 메뉴 14개, 전체 포함 카테고리 12개로 스크롤을 확인할 수 있습니다.
- 옵션 창에서도 끝에서 늘어나는 효과를 제거했습니다.
- Language 메뉴와 기존 메뉴 선택·옵션·장바구니 기능은 유지합니다.

글자 크기는 현재 주문 화면을 나갔다가 다시 들어오면 기본 100%로 돌아옵니다.
관리자·점주 담당자의 실제 화면이나 로그인 기능은 아직 연결하지 않았습니다.

## 파일 역할

- role_select_screen.dart: 포장·매장 식사 시작 화면과 주문 화면 이동
- ../service/screens/order_screen.dart: 주문 화면, 설정 메뉴, 글자 크기 조절
- tests/role_select_test.dart: 두 식사 방식, 설정, 글자 크기, 복귀 검사
- ../main_preview.dart: 시작 화면 확인용 실행 파일

main.dart는 이번 수정에서 변경하지 않았습니다. 주문 화면을 바로 실행합니다.
팀 공통 README, DB 문서와 다른 담당자의 코드는 변경하지 않았습니다.
서비스 상세 내용은 [서비스 안내](../service/README.md)를 참고하세요.

## 실행 방법

VS Code의 아래쪽 터미널을 누릅니다. 기존 Flutter 실행 중이면 q로 종료하고 다음을 실행합니다.

```powershell
cd C:\AI-Voisk\kiosk_app
flutter run -t lib/main_preview.dart
```

같은 실행 파일이 이미 실행 중이면 터미널에서 대문자 R로 다시 시작할 수 있습니다.

## 직접 확인할 항목

1. 포장 / 매장 식사 버튼을 각각 누르고 제목에 선택 내용이 표시되는지 확인합니다.
2. 왼쪽 아래 설정을 누르고 관리자·점주 안내를 확인합니다.
3. 글자를 작게·크게 조절한 뒤 메뉴 선택 창, 장바구니, 합계가 읽기 편한지 확인합니다.
4. 메뉴 담기, 옵션 수정, 수량 변경, 삭제가 기존처럼 동작하는지 확인합니다.
